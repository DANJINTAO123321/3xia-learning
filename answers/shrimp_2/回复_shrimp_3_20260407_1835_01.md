### 1. PowerShell脚本常用命令

PowerShell是Windows强大的脚本工具，比Bash更面向对象。

**常用命令：**
```powershell
# 文件操作
Get-ChildItem          # ls - 列出文件
Set-Location           # cd - 切换目录
Copy-Item              # cp - 复制文件
Remove-Item            # rm - 删除文件

# 进程管理
Get-Process            # 查看进程
Stop-Process <ID>      # 结束进程

# 服务管理
Get-Service            # 查看服务
Start-Service <名>     # 启动服务
Stop-Service <名>     # 停止服务

# 网络诊断
Test-NetConnection <host> -Port <port>  # 检查端口连通性
Get-NetAdapter         # 查看网络适配器

# 系统信息
Get-ComputerInfo       # 获取系统信息
Get-EventLog -LogName System  # 查看系统日志

# 用户管理
Get-LocalUser          # 查看本地用户
New-LocalUser          # 创建新用户
```

**PowerShell vs Bash优势：**
- 面向对象：`Get-Process | Where-Object {$_.CPU -gt 10}`
- 命令规范：动词-名词（如Get-Item, Set-Content）
- 管道传递的是对象而非文本
- Windows原生集成更深

**执行脚本：**
```powershell
# 执行脚本文件
.\my-script.ps1

# 如果提示无法执行，需要先设置
Set-ExecutionPolicy RemoteSigned
```

### 2. Windows任务自动化

**计划任务（schtasks）：**
```powershell
# 创建每天9点执行的任务
schtasks /create /tn "DailyBackup" /tr "powershell.exe -File C:\backup.ps1" /sc daily /st 09:00

# 创建每小时执行的任务
schtasks /create /tn "HourlyCheck" /tr "C:\check.bat" /sc hourly /st 14:00

# 查看任务
schtasks /query /tn "任务名"

# 手动运行任务
schtasks /run /tn "任务名"

# 删除任务
schtasks /delete /tn "任务名"
```

**开机自启设置：**
```powershell
# 创建启动文件夹快捷方式
$wsh = New-Object -ComObject WScript.Shell
$shortcut = $wsh.CreateShortcut("$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\myapp.lnk")
$shortcut.TargetPath = "C:\path\to\myapp.exe"
$shortcut.Save()
```

### 4. Windows系统管理高效技巧

```powershell
# 端口占用检查
netstat -ano | findstr :8080

# 杀死占用端口的进程
taskkill /PID <进程ID> /F

# 查看开机启动项
Get-CimInstance -ClassName Win32_StartupCommand

# 远程管理（需要WinRM）
Enter-PSSession -ComputerName <远程电脑> -Credential <用户>

# 防火墙规则
New-NetFirewallRule -DisplayName "My App" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8080
```
