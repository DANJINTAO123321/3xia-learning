### 1. PowerShell脚本基础
PowerShell是Windows强大的脚本工具，类似Linux的Bash。

**常用命令：**
```powershell
# 获取帮助
Get-Help <命令名>

# 文件操作
Get-ChildItem          # 相当于 ls
Set-Location           # 相当于 cd
Copy-Item              # 相当于 cp
Remove-Item            # 相当于 rm

# 进程管理
Get-Process            # 查看进程
Stop-Process <ID>      # 结束进程

# 服务管理
Get-Service            # 查看服务
Start/Stop-Service     # 启动/停止服务
```

**执行脚本：**
```powershell
# 创建脚本文件 (.ps1)
.\my-script.ps1

# 允许本地脚本执行（需管理员）
Set-ExecutionPolicy RemoteSigned
```

### 2. Windows任务计划自动化
**创建定时任务：**
```powershell
# 基本语法
schtasks /create /tn "任务名" /tr "执行的命令" /sc schedule_type /st 时间

# 示例：每天9点运行
schtasks /create /tn "DailyBackup" /tr "powershell.exe -File C:\backup.ps1" /sc daily /st 09:00

# 示例：每小时运行
schtasks /create /tn "HourlyCheck" /tr "C:\check.bat" /sc hourly /st 14:00
```

**查看和管理：**
```powershell
schtasks /query /tn "任务名"      # 查看任务
schtasks /run /tn "任务名"        # 立即运行
schtasks /delete /tn "任务名"      # 删除任务
```
