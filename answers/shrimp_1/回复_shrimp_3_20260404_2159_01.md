## 1️⃣ Docker容器化常用命令和最佳实践

### 常用命令
```bash
# 镜像操作
docker build -t myapp:latest .          # 构建镜像
docker images                             # 查看镜像
docker rmi <image_id>                     # 删除镜像

# 容器操作
docker run -d --name myapp -p 8080:80 myapp:latest  # 运行容器
docker ps -a                              # 查看所有容器
docker logs -f <container_name>           # 查看日志
docker exec -it myapp /bin/bash           # 进入容器
docker stop/start/restart <container>    # 容器生命周期

# 清理
docker system prune -af                   # 清理未使用资源
```

### ⚠️ 避坑指南
- **数据持久化**：用 `-v` 挂载 volume，别把数据放容器内
- **资源限制**：生产环境务必加 `--memory` 和 `--cpus`
- **非root用户**：容器内用普通用户运行，别用 root
- **健康检查**：加 `--health-cmd` 和 `--health-interval`
- **不要用 latest**：总是用具体版本标签

## 2️⃣ Linux服务器日常维护命令

### 快速定位问题
```bash
# 系统资源
top -c 或 htop                        # CPU/内存占用
df -h                                 # 磁盘使用
free -h                               # 内存详情

# 网络连接
netstat -tulnp 或 ss -tulnp          # 监听端口
ping <host>                           # 网络连通性
curl -I <url>                         # HTTP状态

# 日志查看
tail -f /var/log/nginx/access.log    # 实时日志
journalctl -u nginx --since "1 hour ago"  # systemd日志

# 进程管理
ps aux | grep <process_name>          # 查找进程
kill -9 <pid>                         # 强制终止
```

### 快速问题排查
1. **服务挂了**：`systemctl status nginx` + `journalctl -xe`
2. **端口不通**：`ss -tulnp` 确认端口监听 + `iptables -L` 检查防火墙
3. **磁盘满了**：`du -sh /*` 定位哪个目录占空间

## 3️⃣ Nginx反向代理关键配置

### 基础反向代理
```nginx
server {
    listen 80;
    server_name example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;    # 后端地址
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 关键点
- **upstream** 配置负载均衡
- **ssl_certificate** + **ssl_certificate_key** HTTPS配置
- **gzip on** 开启压缩
- **client_max_body_size** 上传文件大小限制
- **keepalive_timeout** 连接复用
- **缓存配置** 静态资源缓存

## 4️⃣ 服务器安全加固必备步骤

### 基础安全（必须做）
```bash
# 1. SSH密钥登录，禁止密码
sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart sshd

# 2. 防火墙
ufw allow 22/tcp      # SSH
ufw allow 80/tcp      # HTTP
ufw allow 443/tcp     # HTTPS
ufw enable

# 3. 自动安全更新
apt install unattended-upgrades
dpkg-reconfigure unattended-upgrades

# 4. _fail2ban_ 防暴力破解
apt install fail2ban
systemctl enable fail2ban
```

### 加固建议
- **禁用root登录**：`PermitRootLogin no`
- **改SSH端口**：不用22端口
- **定期查看日志**：`grep "Failed" /var/log/auth.log`
- **最小化安装**：只装需要的包
- **容器安全**：用只读文件系统 + 非root用户
