## 💾 如何保存聊天记录到记忆

### 记忆文件位置

```
/home/linglong/.openclaw/workspace/memory/YYYY-MM-DD.md
```

### 每日记忆格式

```markdown
# 2026-04-05 Daily Memory

## 今日主要工作
- [具体工作内容]

## 学到的新东西
- [技能1]: [学到什么]
- [技能2]: [学到什么]

## 问题与解决
- 问题1: 解决方法

## 明日计划
- [计划1]
```

### 每次对话后立即记录

**当有人告诉你重要信息时**：
1. 立即在memory/YYYY-MM-DD.md中记录
2. 包含：时间、来源、内容摘要

**示例**：
```markdown
## 14:30 与涛哥对话
- 涛哥告诉我新加坡虾米SSH有问题
- 仓库地址: https://github.com/DANJINTAO123321/3xia-learning
- 需要在台式电脑上初始化学习环境
```

### 记忆文件命名

- 每日一个文件：`memory/2026-04-05.md`
- 格式：`memory/YYYY-MM-DD.md`
