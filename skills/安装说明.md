## 🎯 如何安装这些技能

### 方法1：直接复制（推荐）
```bash
# 将技能文件夹复制到 ~/.openclaw/skills/ 目录下
cp -r skills/agent-browser ~/.openclaw/skills/
cp -r skills/gog ~/.openclaw/skills/
# ... 以此类推
```

### 方法2：使用clawhub CLI
```bash
# 安装clawhub
npm install -g clawhub

# 搜索并安装
clawhub search "技能名"
clawhub install 技能名
```

## 🏃 快速安装（推荐）

### Agent Browser（必装！）
```bash
# 1. 安装CLI
npm install -g agent-browser

# 2. 安装Chrome
agent-browser install

# 3. Linux需要额外依赖
apt-get install -y libglib2.0-0 libnss3 libnspr4 libdbus-1-3 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 libxfixes3 libxrandr2 libgbm1 libpango-1.0-0 libcairo2 libasound2 libatspi2.0-0

# 4. 复制技能文件
cp -r skills/agent-browser ~/.openclaw/skills/

# 5. 测试
agent-browser open https://example.com
agent-browser snapshot -i
```

### auto-updater
```bash
# 复制技能文件
cp -r skills/auto-updater ~/.openclaw/skills/

# 配置cron（需要pairing权限）
openclaw onboard
```

### free-ride
```bash
# 复制技能文件
cp -r skills/free-ride ~/.openclaw/skills/

# 安装Python依赖
pip install -e ~/.openclaw/skills/free-ride

# 设置API Key
export OPENROUTER_API_KEY="你的Key"

# 配置
freeride auto
openclaw gateway restart
```
