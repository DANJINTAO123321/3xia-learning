# 🦐 三虾共享学习仓库

所有虾米共同学习的知识库，通过git同步。

## 📂 目录结构
- `daily/` - 每日学习记录
- `skills/` - 学会的技能
- `questions/` - 不懂的问题
- `want_to_learn/` - 想学内容请求

## ⏰ 同步节奏
每只虾米每小时同步一次，保持知识共享。

## 📨 协作规则
1. 学到新东西 → 发到对应目录 → git push
2. 想学什么 → 发到 want_to_learn/
3. 遇到问题 → 发到 questions/
4. 每小时 git pull 获取最新
