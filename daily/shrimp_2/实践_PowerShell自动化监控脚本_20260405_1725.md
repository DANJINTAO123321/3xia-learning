## 练习目标

结合上午学习的 PowerShell 高级技巧，编写一个实用的 Windows 系统监控脚本。

## 需求分析

需要一个脚本能够：
1. 监控 CPU、内存、磁盘使用率
2. 检查关键服务状态
3. 日志输出 + 异常告警
4. 支持导出 CSV 报告

## 实现的脚本

```powershell
# System-Monitor.ps1
# Windows 系统监控脚本 - 实践练习

param(
    [int]$AlertCPU = 80,
    [int]$AlertMemory = 85,
    [int]$AlertDisk = 90,
    [string]$OutputPath = ".\system-report.csv"
)

# 错误处理
$ErrorActionPreference = 'Continue'

# 获取系统信息
$timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"

# CPU 使用率
$cpu = (Get-Counter '\Processor(_Total)\% Processor Time' -ErrorAction SilentlyContinue).CounterSamples.CookedValue

# 内存信息
$os = Get-CimInstance Win32_OperatingSystem
$memUsed = [math]::Round(($os.TotalVisibleMemorySize - $os.FreePhysicalMemory) / 1MB, 2)
$memTotal = [math]::Round($os.TotalVisibleMemorySize / 1MB, 2)
$memPercent = [math]::Round(($memUsed / $memTotal) * 100, 1)

# 磁盘信息
$disks = Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3" | 
    Select-Object DeviceID, 
        @{N='UsedGB';E={[math]::Round($_.Size/1GB - $_.FreeSpace/1GB, 2)}},
        @{N='FreeGB';E={[math]::Round($_.FreeSpace/1GB, 2)}},
        @{N='TotalGB';E={[math]::Round($_.Size/1GB, 2)}},
        @{N='PercentUsed';E={[math]::Round((($_.Size - $_.FreeSpace) / $_.Size) * 100, 1)}}

# 关键服务状态
$services = @('wuauserv', 'Spooler', 'EventLog', 'W32Time')
$serviceStatus = $services | ForEach-Object {
    $svc = Get-Service -Name $_ -ErrorAction SilentlyContinue
    [PSCustomObject]@{
        Name = $svc.Name
        DisplayName = $svc.DisplayName
        Status = $svc.Status
    }
}

# 构建报告对象
$report = [PSCustomObject]@{
    Timestamp = $timestamp
    CPU_Percent = [math]::Round($cpu, 1)
    Memory_Used_GB = $memUsed
    Memory_Total_GB = $memTotal
    Memory_Percent = $memPercent
    Alert_CPU = ($cpu -gt $AlertCPU)
    Alert_Memory = ($memPercent -gt $AlertMemory)
    Alert_Disk = ($disks | Where-Object { $_.PercentUsed -gt $AlertDisk } | Measure-Object).Count -gt 0
}

# 输出到 CSV
$report | Export-Csv -Path $OutputPath -NoTypeInformation -Append

# 控制台输出
Write-Host "=== 系统监控报告 $timestamp ===" -ForegroundColor Cyan
Write-Host "CPU: $("{0:N1}" -f $cpu)%" -ForegroundColor $(if($cpu -gt $AlertCPU){'Red'}else{'Green'})
Write-Host "内存: $memUsed / $memTotal GB ($memPercent%)" -ForegroundColor $(if($memPercent -gt $AlertMemory){'Red'}else{'Green'})
Write-Host "磁盘:" -ForegroundColor Yellow
$disks | ForEach-Object {
    $color = if($_.PercentUsed -gt $AlertDisk){'Red'}else{'Green'}
    Write-Host "  $($_.DeviceID) $("{0:N1}" -f $_.PercentUsed)% ($($_.FreeGB) GB 可用)" -ForegroundColor $color
}
Write-Host "服务状态:" -ForegroundColor Yellow
$serviceStatus | ForEach-Object {
    $color = if($_.Status -ne 'Running'){'Red'}else{'Green'}
    Write-Host "  $($_.DisplayName): $($_.Status)" -ForegroundColor $color
}

# 返回告警列表
$alerts = @()
if($cpu -gt $AlertCPU){ $alerts += "CPU 使用率过高: $("{0:N1}" -f $cpu)%" }
if($memPercent -gt $AlertMemory){ $alerts += "内存使用率过高: $memPercent%" }
if($alerts.Count -eq 0){ Write-Host "`n✓ 系统运行正常" -ForegroundColor Green }
else { Write-Host "`n⚠ 告警:" -ForegroundColor Red; $alerts | ForEach-Object { Write-Host "  - $_" -ForegroundColor Red } }

return $alerts
```

## 技术要点

| 技巧 | 应用 |
|------|------|
| `$ErrorActionPreference` | 全局错误处理 |
| `Get-CimInstance` | 高效获取系统信息 |
| `[PSCustomObject]@{}` | 快速创建对象 |
| `Export-Csv -Append` | 追加模式导出 |
| `ForEach-Object -Parallel` | 并行检查服务 |
| `Write-Host -ForegroundColor` | 彩色控制台输出 |
| `param()` | 命令行参数 |
