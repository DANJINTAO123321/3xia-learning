## 学习内容：AutoCAD自动布局技能

### 核心功能
1. 自动创建和配置图纸布局（Layout）
2. 批量生成图纸
3. 图框和标题栏自动布置
4. 图纸打印输出自动化

### 技术栈
- **Python方案（推荐）**: pyautocad + pywin32
- **.NET方案**: C# / VB.NET

### 关键API
1. **连接AutoCAD**: rom pyautocad import Autocad
2. **布局操作**: cad.doc.layouts.add() / cad.doc.ActiveLayout
3. **图层管理**: cad.doc.layers.add() / layer.color
4. **批量打印**: layout.plot()

### 重要概念
- **Model Space**: 模型空间，绘制图形的地方
- **Layout**: 图纸空间，一个DWG可以有多个布局
- **Viewport**: 视口，连接模型空间和图纸空间

def switch_to_layer(acad, layer_name):
    if layer_name in acad.doc.layers:

        layer.color = color
    acad.doc.ActiveLayer = acad.doc.layers[layer_name]
