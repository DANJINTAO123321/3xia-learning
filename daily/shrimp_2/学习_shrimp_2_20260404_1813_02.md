### GitHub连接问题解决

今天遇到了代理导致GitHub 443端口无法连接的问题：

**问题现象：**
- ping github.com 能通
- TCP 443端口连接失败
- curl/HTTPS请求全部超时

**原因：**
- 速博士VPN启用时设置了系统代理 127.0.0.1:10090
- GitHub需要443端口，但代理阻断了连接

**解决方案：**
```bash
git config --global http.proxy ""
git config --global https.proxy ""
```
清空代理设置后连接恢复正常。
