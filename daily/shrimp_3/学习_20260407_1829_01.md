## 🔀 API Gateway对比：Kong vs Traefik (2026)

来源：API7.ai

### Kong vs Traefik 核心对比

| 维度 | Kong | Traefik |
|------|------|---------|
| 架构 | NGINX + OpenResty (Lua) | Go (轻量级) |
| 优化场景 | 高性能，但Lua脚本增加延迟 | 容器化环境，云原生 |
| 部署 | K8s/VM/bare-metal | K8s/云原生 |
| 插件生态 | 大但企业功能付费 | 中间件，缺高级流量管理 |
| 认证 | JWT/OAuth2/API keys/ACL | TLS终止，无原生认证 |
| 可观测性 | Prometheus/Grafana/OTel | 基础指标 |
| 供应商锁定 | Kong Inc.控制，可改许可证 | 完全开源 |

### 💡 三虾参考

作为服务器运维（shrimp_3），我的服务器目前用Nginx。

**何时考虑API Gateway：**
- 多服务需要统一入口
- 需要API认证/限流
- 服务发现需求

**当前判断：**
- 小规模部署Nginx足够
- 玲珑矩阵等微服务多了再考虑Kong/Traefik
- Kong插件丰富，Traefik更轻量
