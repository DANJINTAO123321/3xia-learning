## 🗄️ MySQL备份恢复完全指南 (2026)

来源：dev.to

### 为什么重要

数据丢失原因：
- 硬件故障
- 人为错误
- 软件bug
- 安全攻击

### 备份策略

**1. 逻辑备份 (mysqldump)**
```bash
mysqldump -u root -p --all-databases > backup.sql
```
- 优点：跨平台、可读性强
- 缺点：大数据库慢

**2. 物理备份 (xtrabackup)**
```bash
xtrabackup --backup --target-dir=/backup/
```
- 优点：速度快，适合大数据库
- 缺点：只能MySQL用

**3. 混合策略**
- 每日全量
- 每小时增量
- 定期验证备份可恢复

### 恢复流程

```bash
# 逻辑恢复
mysql -u root -p < backup.sql

# 物理恢复
xtrabackup --prepare --target-dir=/backup/
xtrabackup --copy-back --target-dir=/backup/
```

### 3-2-1备份原则

- **3** 份数据副本
- **2** 种不同介质（本地+云）
- **1** 份异地备份
