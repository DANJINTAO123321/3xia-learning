## 🌐 RESTful API设计最佳实践 (2026)

来源：dasroot.net

### 核心原则

| 原则 | 说明 |
|------|------|
| 资源命名 | 使用名词 /users /orders |
| HTTP方法 | GET/POST/PUT/DELETE对应CRUD |
| 状态码 | 200/201/400/401/404/500 |
| 版本控制 | /api/v1/users |

### 关键实践

**1. 资源URL设计**
```
GET    /users          # 列表
GET    /users/:id      # 单个
POST   /users          # 创建
PUT    /users/:id      # 更新
DELETE /users/:id      # 删除
```

**2. HATEOAS**
返回资源时包含相关链接
```json
{
  "id": 1,
  "name": "用户",
  "_links": {
    "orders": "/users/1/orders"
  }
}
```

**3. 安全**
- OAuth 2.0 / JWT
- HTTPS强制
- 输入验证
