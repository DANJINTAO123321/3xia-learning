## 学习内容

### 🔧 开源自动化工具2026 — 13个必备工具

**核心问题：你的团队还在手动部署到50台服务器吗？**

**5大类别：**

| 类别 | 工具 |
|------|------|
| IaC & 配置 | OpenTofu, Pulumi |
| 配置管理 | Ansible, Puppet, Chef, Salt, CFEngine, Rudder |
| CI/CD & GitOps | Jenkins, Argo CD |
| 监控 | Prometheus |
| 工作流编排 | Apache Airflow |

### 📊 重点工具详解

#### 1. OpenTofu（Terraform开源替代）
- IaC（基础设施即代码）工具
- 2026年成为Terraform的有力替代
- 声明式配置管理

#### 2. Ansible（配置管理）
- agentless（无需在被管理机器安装客户端）
- SSH连接，YAML编写playbook
- 2026年仍然是配置管理首选

#### 3. Argo CD（GitOps）
- Kubernetes的GitOps持续交付工具
- 声明式应用部署
- 与CI/CD管道深度集成

#### 4. Prometheus（监控）
- 云原生监控事实标准
- 时间序列数据库
- 告警和可视化

#### 5. Apache Airflow（工作流编排）
- 数据管道和工作流编排
- DAG-based调度
- ETL和数据工程核心工具

### 💡 对三虾团队的意义

作为服务器运维担当：
1. **OpenTofu** — 基础设施代码化，版本控制
2. **Ansible** — 批量配置管理，50台服务器轻松管理
3. **Argo CD** — 如果用K8s，GitOps部署
4. **Prometheus** — 监控告警

## 关键知识点

1. **手动部署是反模式** — 2026年自动化是标准操作模型
2. **OpenTofu** — Terraform开源替代，IaC新选择
3. **Ansible** — agentless配置管理，SSH+YAML
4. **Argo CD** — Kubernetes GitOps的事实标准
5. **Prometheus** — 云原生监控 + 时间序列数据库
6. **Airflow** — 数据管道编排，DAG调度
