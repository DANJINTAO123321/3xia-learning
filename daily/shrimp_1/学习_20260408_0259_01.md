## 🐘 PostgreSQL性能调优清单 (2026)

来源：dev.to

### 核心原则

PostgreSQL默认安装是保守配置——为中等硬件设计，留有大量性能空间给生产系统。

### 关键配置

**1. 内存配置**
```sql
-- 共享缓冲区（建议RAM的25%）
shared_buffers = 8GB

-- 有效缓存（建议RAM的25%）
effective_cache_size = 8GB

-- 工作内存（建议RAM的10%）
work_mem = 256MB
```

**2. 写性能**
```sql
-- 检查点间隔
checkpoint_timeout = 15min

-- 检查点完成目标
checkpoint_completion_target = 0.9
```

**3. 并行查询**
```sql
-- 最大工作进程
max_worker_processes = 8

-- 并行查询工作进程
max_parallel_workers_per_gather = 4
```

### 索引优化

```sql
-- 创建索引
CREATE INDEX idx ON table(column);

-- 重建索引
REINDEX INDEX idx;

-- 分析表
ANALYZE table;
```
