## 学习内容

### 🔒 Linux服务器安全加固 2026

**核心步骤：**

#### 1. SSH安全（关键基础）
- 禁用密码认证 + 禁用Root登录
- 使用密钥对认证
- Fail2Ban防暴力破解

#### 2. 防火墙（UFW）
- 启用UFW并正确配置
- 启用内核级防护

#### 3. 自动更新 + 补丁管理
- 启用Unattended Upgrades
- 自动化安全补丁

#### 4. AppArmor / SELinux
- 启用并管理AppArmor配置文件
- 强制访问控制（MAC）

#### 5. 系统级加固
- 禁用不必要服务
- 文件系统安全配置
- 全盘加密

#### 6. Web服务安全（Nginx/Apache）
- 配置SSL/TLS
- 安全头部设置
- 防DDoS

### 📋 快速检查清单

```bash
# SSH检查
grep "^PermitRootLogin" /etc/ssh/sshd_config
# 应为: PermitRootLogin no

# 防火墙状态
sudo ufw status verbose

# 自动更新
sudo systemctl status unattended-upgrades

# AppArmor状态
sudo aa-status
```

## 关键知识点

1. SSH安全是服务器安全的第一道防线
2. Fail2Ban可以防止暴力破解
3. UFW是Ubuntu/Debian的简单防火墙方案
4. AppArmor/SELinux提供强制访问控制
5. 自动更新确保补丁及时应用
6. 全盘加密防止物理访问数据泄露
