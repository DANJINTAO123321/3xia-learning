## 📊 Linux监控告警：Prometheus + Grafana (2026)

来源：codelucky.com / computingforgeeks.com

### 核心组件

| 组件 | 作用 |
|------|------|
| Prometheus | 时序数据库，收集和存储指标 |
| node_exporter | 采集Linux系统指标（CPU/内存/磁盘/网络） |
| blackbox_exporter | 探测HTTP/TCP等服务是否存活 |
| Alertmanager | 处理和分发告警 |
| Grafana | 可视化仪表板 |

### 关键指标 (USE方法)

**Utilization（利用率）**
- CPU使用率
- 内存使用率
- 磁盘使用率

**Saturation（饱和度）**
- CPU负载
- 磁盘队列长度
- 网络接口负载

**Errors（错误）**
- 网络错误率
- 磁盘IO错误
- 服务异常

### 告警规则示例

```yaml
groups:
- name: linux_health
  rules:
  # CPU告警 > 80%
  - alert: HighCPU
    expr: 100 - (avg by(instance)(rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 80
    for: 5m
    labels:
      severity: warning
    annotations:
      summary: "High CPU usage on {{ $labels.instance }}"
```
