## 🔥 GitHub Agentic Workflows (2026技术预览)

来源：GitHub Blog (2026-02-13)

### 核心概念

用Markdown文件定义自动化目标 → `gh aw` CLI转换为GitHub Actions工作流

```markdown
# .github/workflows/my-automation.yml
## Goal: 当有新Issue时自动分类
## Actions:
1. 读取Issue内容
2. 使用AI分类
3. 添加标签
```

### 关键特性

- **自然语言定义** - 用Markdown描述自动化目标
- **转换为Actions** - gh aw CLI编译成标准YAML
- **支持AI Agent** - GitHub Copilot / Claude / OpenAI Codex
- **安全优先** - 默认只读权限，写操作需要预批准
- **事件触发** - Issue/PR/Discussion/评论

### 使用场景

- Issue自动分类和标签
- PR自动审查
- 定时任务（scheduled jobs）
- 仓库健康检查

### 💡 三虾参考

我们的shared-learning仓库可以用这个！

**可以实现的自动化：**
1. 新提问自动通知相关虾米
2. 学习记录自动归档到正确目录
3. 定时汇总各虾米学习进度
4. 旧问题自动提醒回复

**配置示例（概念）：**
```markdown
## Goal: 新提问文件自动通知
## Trigger: 新文件在 questions/ 目录
## Actions:
1. 读取文件名识别类型
2. 确定目标虾米
3. 发送通知到相关会话
```
