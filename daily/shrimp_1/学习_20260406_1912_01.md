## 一、SketchUp插件标准架构（官方模板）

### 目录结构
```
tut_hello_cube/                    # 插件根目录（必须与.rb文件名一致）
├── tut_hello_cube.rb             # 插件注册文件（只负责注册）
└── tut_hello_cube/               # 功能代码子目录
    └── main.rb                    # 实际功能代码
```

### 文件1：插件注册文件 (tut_hello_cube.rb)
```ruby
# Copyright 2016 Trimble Inc
# Licensed under the MIT license

# 关键：必须require这两个文件
require 'sketchup.rb'      # 提供 file_loaded? 和 file_loaded
require 'extensions.rb'     # 提供 SketchupExtension 类

# 重要：所有代码必须放在自己的命名空间模块中
module Examples
  module HelloCube
    unless file_loaded?(__FILE__)  # 防止重复注册的守卫
      
      # 创建扩展实例，两个参数：名称 和 主文件路径（无.rb后缀）
      ex = SketchupExtension.new('Hello Cube', 'tut_hello_cube/main')
      
      # 扩展信息（Extension Warehouse要求）
      ex.description = 'SketchUp Ruby API example creating a cube.'
      ex.version     = '1.0.0'
      ex.copyright   = 'Trimble Navigations © 2016'
      ex.creator     = 'SketchUp'
      
      # 注册！第二个参数true表示默认启用
      Sketchup.register_extension(ex, true)
      
      file_loaded(__FILE__)  # 标记为已加载
    end
  end
end
```

**关键要点：**
1. 注册文件**只做注册**，不包含功能代码
2. `SketchupExtension.new('名称', '路径')` - 路径不含.rb
3. 必须用`unless file_loaded?(__FILE__)`防止重复注册
4. `Sketchup.register_extension(ex, true)`第二个参数true=默认启用

### 文件2：主功能文件 (main.rb)
```ruby
require 'sketchup.rb'

module Examples
  module HelloCube
    def self.create_cube
      model = Sketchup.active_model
      
      # ★★★ 关键：所有模型修改必须包在 operation 中 ★★★
      # 第一个参数是Undo菜单显示的名称
      # 第二个参数true表示允许子操作（用于复杂操作）
      model.start_operation('Create Cube', true)
      
      # 创建组（图元必须放在组里）
      group = model.active_entities.add_group
      entities = group.entities
      
      # 定义1米×1米的正方形（ SketchUp内部单位是英寸）
      # Numeric类被扩展了 .m 表示米，.mm表示毫米等
      points = [
        Geom::Point3d.new(0,   0,   0),
        Geom::Point3d.new(1.m, 0,   0),
        Geom::Point3d.new(1.m, 1.m, 0),
        Geom::Point3d.new(0,   1.m, 0)
      ]
      
      # 创建面
      face = entities.add_face(points)
      
      # 推拉（负数表示向上拉伸）
      face.pushpull(-1.m)
      
      model.commit_operation  # 结束操作
    end
    
    # 添加菜单项
    unless file_loaded?(__FILE__)
      menu = UI.menu('Plugins')
      menu.add_item('01 Create Cube Example') {
        self.create_cube
      }
      file_loaded(__FILE__)
    end
  end
end
```

**核心API总结：**
| API | 说明 |
|-----|------|
| `Sketchup.active_model` | 获取当前模型 |
| `model.start_operation(name, true)` | 开始操作（必须！） |
| `model.commit_operation` | 提交操作 |
| `model.active_entities.add_group` | 创建组 |
| `entities.add_face(points)` | 创建面 |
| `face.pushpull(distance)` | 推拉 |
| `Geom::Point3d.new(x, y, z)` | 创建3D点 |
| `UI.menu('Plugins')` | 获取插件菜单 |

## 二、自定义工具 (Tutorial 02)

### 完整源码分析

```ruby
module Examples
  module CustomTool
    # 自定义工具必须是一个类
    class LineTool
      
      def activate
        # InputPoint用于采样3D点，支持推理（捕捉）
        @mouse_ip = Sketchup::InputPoint.new
        @picked_first_ip = Sketchup::InputPoint.new
        update_ui
      end
      
      def deactivate(view)
        view.invalidate  # 必须调用，清除视口绘制
      end
      
      def onMouseMove(flags, x, y, view)
        if picked_first_point?
          # 使用第一个点锁定推理
          @mouse_ip.pick(view, x, y, @picked_first_ip)
        else
          @mouse_ip.pick(view, x, y)
        end
        view.tooltip = @mouse_ip.tooltip if @mouse_ip.valid?
        view.invalidate
      end
      
      def onLButtonDown(flags, x, y, view)
        if picked_first_point? && create_edge > 0
          # 创建了面，重置工具
          reset_tool
        else
          @picked_first_ip.copy!(@mouse_ip)
        end
        update_ui
        view.invalidate
      end
      
      # 绘制预览线
      def draw(view)
        draw_preview(view)
        @mouse_ip.draw(view) if @mouse_ip.display?
      end
      
      def getExtents
        # 返回绘制范围的边界框（防止裁剪）
        bounds = Geom::BoundingBox.new
        bounds.add(picked_points)
        bounds
      end
      
      private
      
      def create_edge
        model = Sketchup.active_model
        model.start_operation('Edge', true)
        edge = model.active_entities.add_line(picked_points)
        # API返回nil而非0
        num_faces = edge.find_faces || 0
        model.commit_operation
        num_faces
      end
    end
    
    # 激活工具的方法
    def self.activate_line_tool
      Sketchup.active_model.select_tool(LineTool.new)
    end
    
    unless file_loaded?(__FILE__)
      menu = UI.menu('Plugins')
      menu.add_item('02 Custom Tool Example') {
        self.activate_line_tool
      }
      file_loaded(__FILE__)
    end
  end
end
```

### 工具类必须实现的回调

| 回调方法 | 调用时机 |
|---------|---------|
| `activate` | 工具被激活时 |
| `deactivate(view)` | 切换到其他工具 |
| `resume(view)` | 从挂起恢复（按住中键时） |
| `suspend(view)` | 工具被挂起 |
| `onCancel(reason, view)` | 用户按ESC |
| `onMouseMove(flags, x, y, view)` | 鼠标移动 |
| `onLButtonDown(flags, x, y, view)` | 左键按下 |
| `draw(view)` | 视口更新时（用于绘制预览） |
| `getExtents` | 返回边界框 |

### InputPoint 推理捕捉
```ruby
@mouse_ip.pick(view, x, y)           # 普通取点
@mouse_ip.pick(view, x, y, ref_pt)    # 锁定到参考点做推理
@mouse_ip.tooltip                     # 获取推理提示
@mouse_ip.valid?                      # 是否有效点
@mouse_ip.position                    # 获取3D坐标
```

## 五、操作Undo机制

```ruby
model.start_operation('操作名称', true)  # true=允许子操作
# ... 做修改 ...
model.commit_operation                  # 提交

# 如果出错，需要回滚
model.abort_operation                   # 放弃所有修改
```

**重要：**
- 每个用户操作必须是**一个undo步骤**
- 不这样做会导致Extension Warehouse审核失败
- 复杂操作要设置 `true` 允许子操作
