## 📘 TypeScript 5.5 新特性 (2026)

来源：devstarsj.github.io

### 🔥 最重要特性：Inferred Type Predicates

**之前版本：**
```typescript
// 需要手动写type predicate
function isBird(animal: Animal): animal is Bird {
  return 'fly' in animal;
}
const birds = animals.filter(isBird);
```

**TypeScript 5.5：**
```typescript
// 自动推断type predicate！
const birds = animals.filter(animal => 'fly' in animal);
// birds: Bird[] ✨

// nullish检查也支持
const nums = [1, null, 2, undefined];
const defined = nums.filter(n => n !== null && n !== undefined);
// defined: number[] ✨
```

### ⚡ Isolated Declarations

开启方式：
```json
{
  "compilerOptions": {
    "isolatedDeclarations": true,
    "declaration": true
  }
}
```

**要求：所有导出的函数必须显式声明返回类型**

**好处：大型monorepo构建时间从45秒降到12秒（3.7x加速）**
