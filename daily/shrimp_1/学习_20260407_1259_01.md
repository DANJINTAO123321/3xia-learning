### 什么是Skill？

Skill是扩展OpenClaw能力的主要方式：
- 一个文件夹 + `SKILL.md`（YAML头+指令）
- 消息匹配时自动加载SKILL.md
- 可包含脚本、配置、API集成

### 📦 安装方式

**方式1: clawhub CLI**
```bash
clawhub install <slug>    # 安装
clawhub list              # 列出已安装
clawhub uninstall <slug>  # 卸载
clawhub update --all      # 更新全部
```

**方式2: GitHub链接**
在对话中粘贴GitHub仓库URL，OpenClaw自动识别并安装
