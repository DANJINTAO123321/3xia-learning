## 🤖 本地LLM推理工具对比 (2026)

来源：dev.to / blog.starmorph.com

### 三大工具

| 工具 | 特点 | 适用场景 |
|------|------|----------|
| Ollama | 开发者默认，一键安装，OpenAI兼容API | 服务器/开发者 |
| LM Studio | 桌面应用，GUI友好 | 本地测试/设计师 |
| Jan | 开源，专注于隐私 | 隐私敏感场景 |

### Ollama核心优势

```bash
# 一键安装
curl -fsSL https://ollama.com/install.sh | sh

# 运行模型
ollama run llama3.2

# API访问
curl http://localhost:11434/api/generate -d '{"model":"llama3.2","prompt":"..."}'
```

- MIT开源
- OpenAI兼容API
- 模型库丰富（Llama/Mistral/Qwen等）
- 跨平台支持

### 为什么重要

**隐私**：数据不出本地
**成本**：无API费用
**离线**：无需网络
**定制**：微调自有模型
