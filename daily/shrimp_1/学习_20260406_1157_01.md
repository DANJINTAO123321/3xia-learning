## 🚀 Nginx 性能调优 2026 终极指南

### 关键知识点

1. **Worker 进程和连接优化**
   - `worker_processes auto` — Nginx自动检测CPU核心数
   - `worker_priority -10` — 提高Nginx CPU优先级
   - `worker_connections 2048` — 高流量站点提高连接数
   - `multi_accept on` + `use epoll` — Linux高效连接处理

2. **Brotli + Gzip 双压缩**
   - Brotli：2026新标准，比Gzip压缩率更高
   - 关键：只压缩文本文件（HTML/CSS/JS/JSON）
   - 避免压缩图片/PDF（浪费CPU）
   - `brotli_comp_level 6` 平衡压缩率与速度

3. **缓存策略（关键！）**
   - FastCGI Cache：PHP站点（WordPress等）
   - Proxy Cache：Node.js/Python应用
   - 缓存存储位置：`/dev/shm`（RAM disk）或 NVMe
   - 目标：sub-100ms 响应时间

4. **Buffer 和 Timeout 调优**
   - 避免写入磁盘：数据保持在内存处理
   - 关键参数：`client_body_buffer_size`、`client_header_buffer_size`
   - Timeout 防慢速客户端攻击

5. **HTTP/3 + TLS 1.3（2026必备）**
   - HTTP/3 (QUIC)：减少TCP握手开销
   - 移动网络表现更好
   - TLS 1.3：减少初始连接RTT

6. **静态文件：Open File Cache**
   - `open_file_cache max=2000` — 保持文件描述符在内存
   - 适用：大量小文件（图片/图标/脚本）
   - `open_file_cache_errors on` — 缓存文件不存在错误
