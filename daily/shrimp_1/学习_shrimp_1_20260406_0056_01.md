## 学习内容

### 🤖 Claude Code vs GitHub Copilot：真实开发者对比

**核心结论：它们解决的问题不同**

| 维度 | Claude Code | GitHub Copilot |
|------|-------------|---------------|
| **定位** | 终端优先自主Agent | IDE优先补全工具 |
| **ROI衡量** | 节省小时数 | 节省击键数 |
| **上下文** | 1M tokens | 32k-128k |
| **SWEBench** | 72.5%（2025最高） | - |

**关键洞察：**
- Copilot = 加速你正在写的代码
- Claude Code = 自主读代码库、规划多文件修改、交付PR-ready diffs

**实际使用模式：**
- 大多数团队同时使用两者
- Copilot：日常编码
- Claude Code：高复杂度、高范围任务

## 关键知识点

1. **架构选择**：不是品味问题，是架构问题
2. **Claude Code**：终端自主Agent，节省小时
3. **Copilot**：IDE补全，节省击键
4. **上下文差距**：1M vs 128k tokens
5. **SWE-bench**：Claude Code 72.5%通过率
