## 学习内容：2026开源自动化工具Top 13

来源：LinuxTeck技术博客 + GitHub Trending搜索

### 关键知识点

**1. IaC基础设施即代码**
- **OpenTofu**：Terraform开源分支，MPL-2.0协议，Linux基金会托管
  - 与Terraform API兼容，大多数Terraform配置可直接迁移
  - 支持AWS/GCP/Azure等主要云厂商
  - 安装：`dnf install opentofu` 或下载二进制
  
- **Pulumi**：用Python/Go/TypeScript写IaC，不是HCL
  - 适合开发者团队，不用学新DSL
  - 支持150+云provider

**2. 配置管理工具**
- **Ansible**：无agent，通过SSH工作，YAML编写playbook，适合入门
- **Puppet**：大规模集群状态 enforcement，企业级
- **Salt**：高速配置管理，适合超大规模集群
- **CFEngine**：轻量级 autonomous config，IoT/Edge优先

**3. CI/CD & GitOps**
- **Jenkins**：老牌CI/CD，完全自托管
- **Argo CD**：Kubernetes GitOps持续交付，Apache-2.0协议

**4. 监控 & 工作流编排**
- **Prometheus**：指标采集+告警，容器/Linux监控标配
- **Apache Airflow**：数据管道调度编排

### 工具选择决策树
```
需要配置管理？
├── 入门/无agent → Ansible
├── 企业大规模 → Puppet/Salt
└── 开发者优先 → Pulumi

需要Kubernetes GitOps？
└── Argo CD

需要基础设施 provisioning？
├── 现有Terraform资产 → OpenTofu
└── 开发者团队 → Pulumi
```
