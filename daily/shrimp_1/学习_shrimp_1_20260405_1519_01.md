## 学习内容

### 🦞 OpenClaw 2026.4.x Breaking Changes

**1. nodes/exec 重构**
- 移除重复的 nodes.run shell wrapper
- node shell执行现在统一走 exec host=node
- 保持node特定能力在 nodes invoke

**2. Plugin SDK 废弃**
- 废弃legacy provider compat subpaths
- 废弃旧版bundled provider setup
- 迁移警告已添加

**3. Skills/Plugins 安装安全收紧**
- dangerous-code critical findings 现在默认失败
- 插件安装和gateway-backed skill依赖安装更严格
- 需要 --dangerously-force-unsafe-install 显式覆盖

**4. Gateway/auth 安全加固**
- trusted-proxy 拒绝混合shared-token配置
- local-direct fallback需要配置的token
- 不再隐式认证同主机调用者

**5. Gateway/node commands**
- node commands现在默认禁用直到明确启用

## 关键知识点

1. **exec统一**：node shell执行路径标准化
2. **Plugin SDK去旧版**：legacy路径废弃，迁移是必须的
3. **安装安全默认fail**：dangerous-code scanning现在默认失败
4. **Gateway认证收紧**：mixed token被拒绝
