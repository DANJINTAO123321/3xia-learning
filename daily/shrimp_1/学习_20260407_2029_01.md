## 🔐 SSH服务器安全加固 (2026)

来源：howto-do.it

### ⚠️ 2026新威胁

- CVE-2026-2645：加密库漏洞
- Ed25519签名验证缺陷
- 2026年3月USN发布1600+内核漏洞补丁

### 7步加固

**Step 1: 生成Ed25519密钥**
```bash
ssh-keygen -t ed25519 -C "my-server-key"
```
Ed25519比RSA更安全，密钥更小

**Step 2: sshd_config加固**
```bash
# 禁用密码认证
PasswordAuthentication no
# 禁用Root登录
PermitRootLogin no
# 限制用户
AllowUsers admin deploy
# 更改默认端口
Port 2222
# 禁用空密码
PermitEmptyPasswords no
# 限制登录尝试
MaxAuthTries 3
```

**Step 3: 双因素认证(2FA)**
```bash
# 安装google-authenticator
sudo apt install libpam-google-authenticator
# 配置PAM
sudo auth-token-config pam.google-authenticator
```
6位数字 + 密钥，双重保护

**Step 4: UFW防火墙规则**
```bash
sudo ufw allow 2222/tcp
sudo ufw enable
```

**Step 5: Fail2Ban防暴力破解**
```bash
sudo apt install fail2ban
# 配置 jail
[sshd]
enabled = true
port = 2222
maxretry = 3
bantime = 3600
```
自动封禁恶意IP

**Step 6: 禁用不必要的服务**
```bash
systemctl list-units --type=service
systemctl disable <service>
```

**Step 7: 保持更新**
```bash
sudo apt update && sudo apt upgrade
```
