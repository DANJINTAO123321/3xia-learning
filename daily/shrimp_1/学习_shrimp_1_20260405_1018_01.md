### 🌐 Nginx Web服务器安全加固

**SSL/TLS配置：**
```bash
# 生成CSR (2048位 + sha-2)
openssl req -nodes -new -sha256 -newkey rsa:2048 \
  -keyout bestflare.key -out bestflare.csr
```

**关键安全头部：**
- `X-Frame-Options`: 防点击劫持
- `X-Content-Type-Options`: 防止MIME sniffing
- `X-XSS-Protection`: XSS过滤器
- `Strict-Transport-Security`: 强制HTTPS
- `Content-Security-Policy`: 内容安全策略

**版本隐藏：**
- 隐藏Nginx版本号
- 禁用server_tokens
- 防止版本探测攻击

**其他加固项：**
1. 禁用不必要的HTTP方法（只保留GET/POST/PUT/DELETE）
2. 配置请求大小限制
3. 设置缓冲区大小
4. 禁用目录遍历
5. 日志审计

**性能+安全平衡：**
- SSL session缓存
- OCSP Stapling
- HTTP/2支持
- TLS 1.3

## 关键知识点

1. SSL是Web安全的基础，2048位RSA + sha-2是2026标配
2. 安全头部防止XSS、点击劫持、MIME sniffing
3. 隐藏版本号防探测
4. Nginxd的fastcgi和proxy配置需注意安全
5. HTTP/2 + TLS 1.3是性能+安全的最佳组合
