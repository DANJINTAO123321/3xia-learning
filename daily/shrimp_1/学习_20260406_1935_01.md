## 一、Entity遍历核心模式

### 1. 基本遍历（安全模式）

```ruby
model = Sketchup.active_model
entities = model.active_entities

entities.each do |entity|
  puts entity.typename  # "Edge", "Face", "Group", etc.
end
```

**⚠️ 注意：遍历时不要删除实体，会导致索引混乱！**

如果要删除，应该：
```ruby
# 复制到数组再遍历删除
entities_to_delete = []
entities.each { |e| entities_to_delete << e if condition }
entities.erase_entities(entities_to_delete)
```

### 2. 类型筛选

```ruby
# 筛选所有Face
faces = entities.grep(Sketchup::Face)

# 筛选所有Edge
edges = entities.grep(Sketchup::Edge)

# 筛选组和组件实例
groups = entities.grep(Sketchup::Group)
components = entities.grep(Sketchup::ComponentInstance)

# 组合筛选
edges_and_faces = entities.select { |e| 
  e.is_a?(Sketchup::Edge) || e.is_a?(Sketchup::Face)
}
```

### 3. 递归遍历（包含嵌套Group/Component）

```ruby
def traverse_entities(entities, &block)
  entities.each do |entity|
    block.call(entity)
    
    # 递归处理嵌套
    if entity.is_a?(Sketchup::Group) || 
       entity.is_a?(Sketchup::ComponentInstance)
      traverse_entities(entity.entities, &block)
    end
  end
end

# 使用示例：统计所有面
face_count = 0
traverse_entities(model.entities) do |entity|
  face_count += 1 if entity.is_a?(Sketchup::Face)
end
puts "总共有 #{face_count} 个面"
```

### 4. 使用Observers监听变化

```ruby
class MyObserver < Sketchup::EntitiesObserver
  def onEntityAdded(entities, entity)
    puts "添加了新实体: #{entity.typename}"
  end
  
  def onEntityRemoved(entities, entity)
    puts "删除了实体: #{entity.typename}"
  end
end

# 注册观察者
model.entities.add_observer(MyObserver.new)
```

## 二、Edge 详解

### Edge核心属性

```ruby
edge = entities.add_line(point1, point2)

# 端点
edge.start      # Sketchup::Vertex
edge.end        # Sketchup::Vertex

# 长度
length = edge.length              # 当前单位
length_inch = edge.length.to_f    # 英寸

# 变换支持（考虑组的缩放）
true_length = edge.length(group_transformation)

# 线条几何
line = edge.line  # [Point3d, Vector3d]
```

### Edge平滑/软化

```ruby
# 软边（隐藏边，连接面变成光滑表面）
edge.soft = true
edge.soft?  # 查询

# 平滑（面之间平滑过渡，但边仍可见）
edge.smooth = true
edge.smooth?

# 通常软边和平滑一起设置
edge.soft = true
edge.smooth = true
```

### Edge分割与合并

```ruby
# 在指定位置分割边
new_edge = edge.split(0.5)        # 在中点分割
new_edge = edge.split(position)   # 在指定点分割

# 炸开曲线
edges = curve_edge.explode_curve  # 返回组成曲线的边数组
```

### Edge的面关联

```ruby
# 获取边参与的所有面
edge.faces  # 返回 [face1, face2] 或 []

# 找两条边的公共面
common = edge1.common_face(edge2)  # Sketchup::Face or nil

# 判断边是否在面中反向
edge.reversed_in?(face)  # true/false
```

### 顶点操作

```ruby
vertex = edge.start
other = edge.other_vertex(vertex)  # 获取另一个顶点

# 顶点坐标
vertex.position  # Geom::Point3d

# 获取顶点连接的所有边
vertex.edges  # [edge1, edge2, ...]
```

## 三、Face 详解

### Face创建

```ruby
# 从点创建面
points = [p1, p2, p3, p4]
face = entities.add_face(points)

# 从边创建面（会自动填补）
entities.add_face(edge1, edge2, edge3)

# 从曲线创建（必须是封闭曲线）
face = entities.add_face(curve)
```

### Face核心属性

```ruby
face.normal                    # 面法向量 (Vector3d)
face.area                     # 面积
face.plane                    # 平面方程 [a,b,c,d]
face.vertices                 # 顶点数组
face.edges                    # 边数组
face.loops                    # 环数组（含内外环）
face.outer_loop               # 外环
```

### Face面积计算（考虑变换）

```ruby
# 原始面积
area = face.area

# 考虑父组缩放的"视觉"面积
visual_area = face.area(group_transformation)
```

### Face材料

```ruby
# 获取/设置材料
material = face.material
face.material = some_material

# 背面材料
face.back_material = red_material

# 清除材料
face.material = nil
```

### Face推拉

```ruby
# 推拉（距离，面是否复制）
face.pushpull(distance)
face.pushpull(distance, true)  # 复制模式

# 注意：推拉方向沿法线方向
# 正值=沿法线方向
# 负值=逆法线方向
```

### Face纹理

```ruby
# 获取纹理助手
uv_helper = face.get_UVHelper(true, false)

# 获取纹理投影
vec = face.get_texture_projection(true)  # 正面

# 设置材质位置
face.position_material(material, points, true)  # front
```

### Face几何判断

```ruby
# 点是否在面上
result = face.classify_point(point)
# 返回：
# Sketchup::Face::PointInside      - 在面内部
# Sketchup::Face::PointOnVertex    - 在顶点上
# Sketchup::Face::PointOnEdge      - 在边上
# Sketchup::Face::PointOnFace      - 在面上（非内部）
# Sketchup::Face::PointOutside     - 在面外
# Sketchup::Face::PointNotOnPlane - 不在平面

# 是否共面
face.coplanar_with?(other_face)  # true/false
```

### Face的Mesh导出

```ruby
# 获取面的mesh表示
mesh = face.mesh(0)  # 0=基本mesh
mesh_with_uv = face.mesh(7)  # 包含UVQ和法线

# mesh.points    - 所有顶点
# mesh.polygons  - 多边形索引
```

## 四、实用代码模式

### 1. 批量计算总面积

```ruby
def total_area(entities)
  total = 0
  entities.each do |entity|
    if entity.is_a?(Sketchup::Face)
      total += entity.area
    elsif entity.is_a?(Sketchup::Group) || 
          entity.is_a?(Sketchup::ComponentInstance)
      total += total_area(entity.entities)
    end
  end
  total
end

# 使用
model = Sketchup.active_model
puts "总面积: #{total_area(model.entities)} 平方英寸"
```

### 2. 查找最短边

```ruby
def shortest_edge(entities)
  shortest = nil
  min_length = Float::INFINITY
  
  entities.each do |entity|
    next unless entity.is_a?(Sketchup::Edge)
    if entity.length < min_length
      min_length = entity.length
      shortest = entity
    end
  end
  shortest
end
```

### 3. 创建参数化墙体

```ruby
def create_wall(width, height, depth)
  model = Sketchup.active_model
  model.start_operation('Create Wall', true)
  
  # 创建组
  group = model.active_entities.add_group
  entities = group.entities
  
  # 底面
  points = [
    Geom::Point3d.new(0, 0, 0),
    Geom::Point3d.new(width, 0, 0),
    Geom::Point3d.new(width, depth, 0),
    Geom::Point3d.new(0, depth, 0)
  ]
  face = entities.add_face(points)
  face.pushpull(height)
  
  model.commit_operation
  group
end

# 使用
create_wall(300.cm, 240.cm, 20.cm)
```

### 4. 选中面按面积筛选

```ruby
def select_faces_by_area(min_area, max_area)
  model = Sketchup.active_model
  selection = model.selection
  selection.clear
  
  model.entities.each do |entity|
    if entity.is_a?(Sketchup::Face)
      area = entity.area
      selection.add(entity) if area >= min_area && area <= max_area
    end
  end
end

# 使用：选中所有大于1平方英尺的面
select_faces_by_area(144, Float::INFINITY)  # 144 sq inch = 1 sq ft
```

### 5. 边的平滑/软化批量处理

```ruby
def smooth_edges_by_angle(entities, max_angle_deg = 30)
  model = Sketchup.active_model
  model.start_operation('Smooth Edges', true)
  
  entities.each do |entity|
    next unless entity.is_a?(Sketchup::Edge)
    
    # 获取边的两个面的法线夹角
    faces = entity.faces
    next if faces.length < 2
    
    angle = faces[0].normal.angle_between(faces[1].normal)
    angle_deg = angle * 180 / Math::PI
    
    if angle_deg < max_angle_deg
      entity.soft = true
      entity.smooth = true
    end
  end
  
  model.commit_operation
end
```

## 五、EntitiesBuilder 高性能批量创建

当需要创建大量几何体时，使用EntitiesBuilder：

```ruby
model.start_operation('Build Geometry', true)

builder = model.active_entities.build do
  # 在这里批量创建，性能更好
  100.times do |i|
    x = i * 10
    points = [
      Geom::Point3d.new(x, 0, 0),
      Geom::Point3d.new(x + 5, 0, 0),
      Geom::Point3d.new(x + 5, 5, 0),
      Geom::Point3d.new(x, 5, 0)
    ]
    add_face(points)
  end
end

model.commit_operation
```

**⚠️ 使用build时不要用其他方式修改实体！**

## 六、常见问题与解决方案

### Q1: 如何判断点是否在面上？

```ruby
point = Geom::Point3d.new(10, 10, 0)
result = face.classify_point(point)

if result == Sketchup::Face::PointInside
  puts "点在面内部"
elsif result == Sketchup::Face::PointOnEdge
  puts "点在边上"
end
```

### Q2: 如何获取两条边的交点？

```ruby
# Edge没有直接的交点方法，需要通过几何计算
line1 = edge1.line
line2 = edge2.line

# 使用Geom::Intersection.intersect_line_line
point = Geom::Intersection.line_line(line1, line2)
```

### Q3: 如何复制实体？

```ruby
# SketchUp不直接支持复制，需要用transformation
original = entities.add_line(p1, p2)
copy = entities.add_line(p1, p2)
copy.transform!(Geom::Transformation.new(p1, p2))
```

### Q4: 如何获取实体相对于模型的位置？

```ruby
# 对于组内的实体
if entity.parent.is_a?(Sketchup::Group)
  global_transform = entity.parent.transformation * entity.transformation
  global_point = global_transform * entity.bounds.center
end
```
