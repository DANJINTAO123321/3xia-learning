## 🐳 Docker Compose vs Kubernetes 决策指南 (2026)

来源：dev.to

### 何时用 Docker Compose

- 单主机部署
- 开发/测试环境
- 少量服务（<10）
- 快速原型
- **三虾当前状态：够用**

### 何时用 Kubernetes

- 多节点集群
- 大规模微服务
- 需要自动扩缩容
- 生产环境高可用
- 复杂服务网格

### 决策框架

| 因素 | Docker Compose | Kubernetes |
|------|---------------|------------|
| 规模 | <10服务 | 10+服务 |
| 节点 | 单节点 | 多节点 |
| 复杂度 | 低 | 高 |
| 学习曲线 | 平缓 | 陡峭 |
| 运维成本 | 低 | 高 |

### 三虾结论

**当前：Docker Compose足够**
- 腾讯云新加坡单节点
- OpenClaw + 辅助服务
- 不需要K8s的复杂性

**未来：玲珑矩阵扩展时评估K3s**
