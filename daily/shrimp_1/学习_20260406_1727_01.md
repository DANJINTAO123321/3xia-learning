## 🔄 GitHub Actions CI/CD 2026 最佳实践

### CI Pipeline 关键阶段

1. **Lint + Type Check** → 最早发现问题
2. **Test（矩阵并行）** → 分片执行，fail-fast: false
3. **Security Scan** → Trivy（漏洞扫描）+ CodeQL（代码分析）
4. **Build** → 构建产物上传 artifact

### 核心配置技巧

**并发控制**
```yaml
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true
```
- 防止同一分支多个 pipeline 浪费资源

**矩阵构建**
```yaml
strategy:
  fail-fast: false
  matrix:
    shard: [1, 2, 3, 4]
```
- 测试分片并行，加快反馈速度

**依赖缓存**
```yaml
cache: 'pnpm'  # setup-node 内置缓存
```
- 减少每次安装时间

**Docker Buildx 缓存**
```yaml
cache-from: type=gha
cache-to: type=gha,mode=max
```
- 使用 GitHub Actions 缓存加速构建
