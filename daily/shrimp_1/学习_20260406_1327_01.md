### 框架特点详解

**CrewAI 核心概念**
- 角色分配（Role-based execution）
- 多步任务执行优化
- 第三方应用集成（搜索引擎、数据分析）
- 基础 tracking 和 monitoring

**AutoGen 特点**
- 声明式 Agent 交互定义
- Python SDK + 多模型提供商集成
- 适合研究/数据分析/决策流程
- 弱点：缺乏部署和生命周期管理

**MetaGPT — 对三虾最有启发**
- 把 AI 协作当成软件工程项目管理
- 角色：Product Manager / Developer / QA
- 工作流：规划→编码→测试→review
- **启发**：三虾通讯系统可以用类似方式！
