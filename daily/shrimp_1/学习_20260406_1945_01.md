## 一、Component（组件）系统

### 概念区分

| 概念 | 说明 |
|-----|------|
| **ComponentDefinition** | 组件的"模板"，定义组件包含哪些实体 |
| **ComponentInstance** | 组件的"实例"，是模板在模型中的具体放置 |
| **Group** | 组的本质是一个特殊的ComponentDefinition |

### ComponentDefinition 详解

```ruby
# 获取模型中所有组件定义
model = Sketchup.active_model
definitions = model.definitions

# 遍历
definitions.each do |defn|
  puts "组件名: #{defn.name}"
  puts "实例数: #{defn.count_used_instances}"
  puts "GUID: #{defn.guid}"
end

# 按名称查找
chair_def = definitions.find { |d| d.name == 'Chair' }
```

### ComponentDefinition核心方法

```ruby
# 获取定义内的实体（编辑组件内容）
entities = definition.entities

# 获取所有实例
instances = definition.instances

# 统计实例数量
definition.count_instances      # 唯一实例数
definition.count_used_instances  # 包含嵌套的总实例数

# 保存组件到文件
definition.save_as("C:/temp/my_component.skp")

# 获取/设置属性
definition.name = "新名称"
definition.description = "这是组件描述"

# 获取行为设置（组件是朝向相机、始终面向等）
behavior = definition.behavior
```

### ComponentInstance 详解

```ruby
# 创建组件实例
component_def = model.definitions['MyComponent']
point = Geom::Point3d.new(100, 100, 0)
transform = Geom::Transformation.new(point)
instance = model.active_entities.add_instance(component_def, transform)

# 获取实例信息
instance.definition          # 返回 ComponentDefinition
instance.transformation     # 返回 Geom::Transformation
instance.name               # 实例名称
instance.guid               # 唯一ID

# 移动实例（记录到Undo）
new_transform = Geom::Transformation.new(new_point)
instance.transformation = new_transform

# 移动实例（不记录Undo，用于动画）
instance.move!(new_transform)

# 炸开实例为普通实体
entities = instance.explode

# 复制实例（独立副本）
unique_instance = instance.make_unique

# 锁定/解锁
instance.locked = true
instance.locked?

# 获取实例在世界坐标中的实际位置
global_transform = instance.transformation
```

### 创建组件的完整流程

```ruby
def create_door_component(width, height, depth)
  model = Sketchup.active_model
  
  # 1. 在模型中创建几何体
  group = model.active_entities.add_group
  entities = group.entities
  
  # 创建门几何体
  points = [
    Geom::Point3d.new(0, 0, 0),
    Geom::Point3d.new(width, 0, 0),
    Geom::Point3d.new(width, depth, 0),
    Geom::Point3d.new(0, depth, 0)
  ]
  face = entities.add_face(points)
  face.pushpull(height)
  
  # 2. 将组转换为组件定义
  definition = group.to_component
  definition.name = "Door_#{width}x#{height}"
  
  # 3. 创建实例
  instance = model.active_entities.add_instance(
    definition,
    Geom::Transformation.new(Geom::Point3d.new(0, 0, 0))
  )
  
  # 4. 删除原始组
  group.erase!
  
  instance
end
```

### Component与Group的区别

| 特性 | Component | Group |
|-----|-----------|-------|
| 是否可复用 | ✓ 定义可创建多个实例 | 只有单一实体 |
| 是否可嵌套 | ✓ | ✓ |
| 属性 | 有name/description | 无 |
| 行为设置 | 有Behavior | 无 |
| 文件保存 | 可单独保存 | 随模型保存 |

## 二、Transformation（变换）详解

### Transformation概念

Transformation描述了对象的位置、旋转和缩放。包括：
- **平移** (Translation)
- **旋转** (Rotation)
- **缩放** (Scale)
- **镜像** (Mirror/Reflection)

### 创建各种变换

```ruby
# 1. 平移变换
point = Geom::Point3d.new(100, 200, 300)
t1 = Geom::Transformation.new(point)

# 2. 旋转变换（绕Z轴旋转90度）
origin = Geom::Point3d.new(0, 0, 0)
axis = Geom::Vector3d.new(0, 0, 1)  # Z轴
angle = 90.degrees  # 或 Math::PI / 2
t2 = Geom::Transformation.new(origin, axis, angle)

# 3. 缩放变换
scale_factor = 2.0
t3 = Geom::Transformation.new(scale_factor)

# 4. 缩放变换（指定中心点）
center = Geom::Point3d.new(50, 50, 0)
t4 = Geom::Transformation.new(center, scale_factor)

# 5. 镜像变换
plane = [0, 0, 1, 0]  # XY平面
t5 = Geom::Transformation.new(plane)
```

### 变换的组合

```ruby
# 组合变换（先t1后t2）
combined = t2 * t1

# 应用变换到点
original_point = Geom::Point3d.new(10, 20, 0)
new_point = original_point.transform(t1)

# 应用变换到向量
original_vector = Geom::Vector3d.new(1, 0, 0)
new_vector = original_vector.transform(t1)
```

### 从组件实例获取世界坐标

```ruby
# 实例的全局变换
global_transform = instance.transformation

# 实例内某点的世界坐标
local_point = Geom::Point3d.new(10, 10, 0)
world_point = global_transform * local_point

# 获取实例的边界中心的世界坐标
bounds = instance.bounds
center = bounds.center
world_center = global_transform * center
```

## 三、Attribute（属性）系统

### Entity属性字典

每个Entity都可以附加AttributeDictionary，用于存储自定义数据：

```ruby
# 设置属性
entity.set_attribute('MyPlugin', 'color', 'red')
entity.set_attribute('MyPlugin', 'size', 100)

# 读取属性
color = entity.get_attribute('MyPlugin', 'color')
size = entity.get_attribute('MyPlugin', 'size')

# 删除属性
entity.delete_attribute('MyPlugin', 'size')

# 获取所有属性字典
dicts = entity.attribute_dictionaries
```

### Attribute的高级用法

```ruby
# 创建嵌套属性
entity.set_attribute('MyPlugin', 'material', {
  'color' => 'red',
  'texture' => 'wood.png'
})

# 检查字典是否存在
dict = entity.attribute_dictionary('MyPlugin', false)  # false=不自动创建
if dict
  puts "字典存在，包含 #{dict.keys.length} 个键"
end
```

### SketchUp 2018+默认属性

```ruby
# ComponentDefinition有默认的SU_DefinitionSet字典
definition.attribute_dictionaries['SU_DefinitionSet'].each do |key, value|
  puts "#{key}: #{value}"
end
# 默认键: 'Price', 'Size', 'Url'

# ComponentInstance有默认属性
instance.attribute_dictionaries['SU_InstanceSet'].each do |key, value|
  puts "#{key}: #{value}"
end
```

## 四、Layer（图层）系统

### Layer基本操作

```ruby
# 获取所有图层
layers = model.layers

new_layer = layers.add('My Layer')
```

## 五、Material（材料）系统

### Material基本操作

```ruby
# 获取所有材料
materials = model.materials

# 按名称获取/创建材料
material = materials.add('My Material')

# 设置材料颜色（RGB 0-255）
material.color = 'red'
material.color = Sketchup::Color.new(0, 255, 0)  # 绿色

# 设置纹理
material.texture = 'C:/textures/wood.png'

# 设置透明度
material.alpha = 0.5  # 50%透明

# 材料应用到面
face.material = material
face.back_material = other_material  # 背面
```

### 复制材料到模型

当从外部导入几何体时，材料可能被"克隆"：

```ruby
# 获取面上引用的材料
face_material = face.material

# 查找模型中是否已有同名材料
existing = model.materials[face_material.name]

if existing
  # 使用现有材料
  face.material = existing
else
  # 复制新材料到模型
  new_mat = model.materials.add(face_material.name)
  new_mat.copy_from(face_material)
  face.material = new_mat
end
```

## 六、Group（组）详解

### Group与ComponentInstance对比

```ruby
# Group本质上是一个特殊的ComponentDefinition
# Group对应的definition.group? == true

# 创建组
group = model.active_entities.add_group

# 添加几何体到组
face = group.entities.add_face(points)
face.pushpull(height)

# 组的变换
group.transformation = Geom::Transformation.new(point)

# 炸开组
entities = group.explode
```

### 组嵌套

```ruby
# 创建嵌套组
outer_group = model.active_entities.add_group
inner_group = outer_group.entities.add_group

# 递归遍历获取全局变换
def get_global_transform(entity)
  if entity.parent.is_a?(Sketchup::Group) || 
     entity.parent.is_a?(Sketchup::ComponentInstance)
    parent_transform = get_global_transform(entity.parent)
    return parent_transform * entity.transformation
  end
  entity.transformation
end
```

## 七、实用代码模式

### 1. 批量替换组件

```ruby
def replace_component(old_instance, new_definition)
  model = Sketchup.active_model
  model.start_operation('Replace Component', true)
  
  # 保存原实例的位置
  old_transform = old_instance.transformation
  
  # 创建新实例
  new_instance = model.active_entities.add_instance(
    new_definition,
    old_transform
  )
  
  # 删除旧实例
  old_instance.erase!
  
  model.commit_operation
  new_instance
end
```

### 2. 统计组件使用情况

```ruby
def component_usage_report
  model = Sketchup.active_model
  report = {}
  
  model.definitions.each do |defn|
    next if defn.group? || defn.image?
    count = defn.count_used_instances
    if count > 0
      report[defn.name] = count
    end
  end
  
  # 按使用数排序
  sorted = report.sort_by { |name, count| -count }
  
  sorted.each do |name, count|
    puts "#{name}: #{count} instances"
  end
end
```

### 3. 导出所有组件到单独文件

```ruby
def export_all_components
  model = Sketchup.active_model
  output_dir = 'C:/temp/components/'
  
  model.definitions.each do |defn|
    next if defn.group? || defn.image?
    next if defn.count_used_instances == 0
    
    filename = "#{output_dir}#{defn.name.gsub(/[<>:"\/\\|?*]/, '_')}.skp"
    defn.save_as(filename)
    puts "Saved: #{filename}"
  end
end
```

### 4. 递归获取实体的世界边界框

```ruby
def get_world_bounds(entity)
  bounds = entity.bounds
  
  if entity.is_a?(Sketchup::Group) || 
     entity.is_a?(Sketchup::ComponentInstance)
    transform = entity.transformation
    bounds = bounds.transform(transform)
  end
  
  bounds
end

def get_all_bounds(entities)
  combined = Geom::BoundingBox.new
  entities.each do |entity|
    combined.add(get_world_bounds(entity))
  end
  combined
end
```

### 5. 判断实例是否manifold（实体，适合布尔运算）

```ruby
model = Sketchup.active_model
model.selection.each do |entity|
  if entity.is_a?(Sketchup::ComponentInstance)
    if entity.manifold?
      puts "#{entity.definition.name} 可以进行布尔运算"
    else
      puts "#{entity.definition.name} 不是实体，无法布尔运算"
    end
  end
end
```

### 6. 布尔运算（Pro版本）

```ruby
# 注意：需要 SketchUp Pro，且不是 Make 版本

# 合并
result = instance1.union(instance2)

# 差集
result = instance1.subtract(instance2)

# 交集
result = instance1.intersect(instance2)

# 分割（三个结果：交集、差集1、差集2）
intersection, diff1, diff2 = instance1.split(instance2)

# 非破坏性Trim
result = instance1.trim(instance2)  # instance2被删除，生成新实体
```

## 八、API速查表

### ComponentDefinition
| 方法 | 返回 | 说明 |
|-----|------|-----|
| `definition.entities` | Entities | 组件内部实体 |
| `definition.instances` | Array | 所有实例 |
| `definition.count_used_instances` | Integer | 总实例数 |
| `definition.name` | String | 名称 |
| `definition.behavior` | Behavior | 行为设置 |
| `definition.save_as(path)` | Boolean | 保存到文件 |

### ComponentInstance
| 方法 | 返回 | 说明 |
|-----|------|-----|
| `instance.definition` | ComponentDefinition | 获取定义 |
| `instance.transformation` | Transformation | 变换矩阵 |
| `instance.explode` | Array | 炸开 |
| `instance.make_unique` | ComponentInstance | 复制为独立 |
| `instance.locked?` | Boolean | 是否锁定 |
| `instance.move!(transform)` | Boolean | 移动（无Undo） |

### Transformation
| 方法 | 返回 | 说明 |
|-----|------|-----|
| `Geom::Transformation.new(point)` | Transformation | 平移 |
| `Geom::Transformation.new(origin, axis, angle)` | Transformation | 旋转 |
| `t1 * t2` | Transformation | 组合 |
| `point.transform(t)` | Point3d | 应用变换 |
