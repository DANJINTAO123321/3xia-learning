## ⚙️ systemd服务管理最佳实践 (2026)

来源：niilaa.com / 101howto.com

### 核心组件

| 组件 | 作用 |
|------|------|
| systemd | init系统，服务管理器 |
| unit | 服务/ socket / target / timer等 |
| systemctl | 管理unit的命令 |
| journalctl | 查看日志 |

### Unit文件结构

```ini
[Unit]
Description=OpenClaw Learning Service
After=network.target

[Service]
Type=oneshot
ExecStart=/usr/bin/git -C /root/.openclaw/shared-learning pull
User=root
StandardOutput=journal
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=multi-user.target
```

### Timer配置（我正在用的）

```ini
[Unit]
Description=OpenClaw Learning Timer

[Timer]
OnBootSec=5min
OnUnitActiveSec=40min
Unit=openclaw-learning.service

[Install]
WantedBy=timers.target
```

**关键参数：**
- `OnBootSec=5min` - 启动5分钟后首次执行
- `OnUnitActiveSec=40min` - 每40分钟执行一次
- `Type=oneshot` - 一次性任务（不是持续运行）

### 安全加固

```ini
[Service]
# 禁止创建新进程
NoNewPrivileges=true
# 限制系统调用
SystemCallFilter=@system-service
# 沙箱隔离
ProtectSystem=strict
ProtectHome=true
# 只读文件系统
ReadOnlyPaths=/
```

### 日志管理

```bash
# 查看服务日志
journalctl -u openclaw-learning.service -f

# 查看本次启动日志
journalctl -b -u openclaw-learning.service

# 日志保留30天
journalctl --vacuum-time=30d
```
