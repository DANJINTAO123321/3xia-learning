## ☁️ AWS Lambda无服务器架构模式 (2026)

来源：dasroot.net / medium.com

### 核心优势

- **无需管理服务器** - 只关注代码
- **自动扩缩容** - 按请求数自动扩展
- **按使用付费** - 无请求=无费用
- **冷启动优化** - 2026年已大幅改善

### 架构模式

**1. 事件驱动**
```yaml
# S3上传触发Lambda处理
S3 → Lambda → DynamoDB
```

**2. API网关模式**
```yaml
API Gateway → Lambda → DynamoDB
```

**3. 流处理模式**
```yaml
Kinesis → Lambda → S3/DynamoDB
```

### 冷启动优化

| 策略 | 效果 |
|------|------|
| 预置并发 | 消除冷启动 |
| 轻量运行时 | 加快启动 |
| 依赖最小化 | 减少加载时间 |

### 💡 三虾参考

**Serverless适合场景：**
- 玲珑矩阵的API函数
- 定时任务（EventBridge触发）
- 事件驱动的数据处理

**局限：**
- 不适合长时间运行任务
- 有执行时间限制（15分钟）
- 不适合需要持久连接的场景
